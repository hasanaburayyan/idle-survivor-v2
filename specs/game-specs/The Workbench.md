Overview:
The first Structure a player can build, of many. Structures become an interactable element within the Location they exist. To construct a Workbench, we'll say the player needs to perform a task much like Build Shelter, contributing 1000 resources in the same manner. Once constructed, it will have a "Slot" within it that any applicable activity can be placed inside it. Once inside, the activity will be automated once per second. This will function identically to the player clicking the button, as in Groups will benefit from it, and exp will be accrued.

This will be the first automation slot available to the player, in the future players will have many more tasks running in parallel.

Upgrades: Within the Workbench activity panel, you can upgrade it in a few ways. The first Upgrade will be to make Scavenge applicable to be placed in the automation slot. The second upgrade will be "Activity Efficiency" which specifically improves the performance of the activity/s currently slotted. We'll say they're fairly expensive, maybe 5x faster cost scaling than Scavenge has. Each level of upgrade increases yield by 20%.
