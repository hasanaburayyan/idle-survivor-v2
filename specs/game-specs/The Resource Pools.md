Overview:
The player begins with only scrap, and within the skill tree five additional resources can be discovered, and will be added to the UI, and relevant activities will be created alongside them. Each Resource uses every previously discovered resource as unlock, and upgrade conditions.

For example, you begin with scrap, and spend some time upgrading scrap. Once you have 5 points in Base Scavenge Value, a new node is discovered and added to the skill web, off of the root note, called "Unlock Parts", and a new Activity called "Scavenge for Parts" is added to The Wastes. Relevant unlocks can be added to the Workbench, such as unlocking automation for the new activity, and skill tree nodes to increase base value, and percentage values.

After Parts, comes Metal, then Fabric, then Food, then Medicine.

Scavenge - Free, yields scrap
Parts - Costs scrap, new activity obtains parts
Metal - Costs scrap and parts, new activity obtains metal
Fabric - Cost scrap, parts, metal, new activity obtains fabric
Food - Costs all of the above, new activity obtains Food
Medicine - Costs all of the above, new activity obtains Medicine.

Each resource will have similar skill tree nodes, and at the end of each of the new resource tree chains, a node called "Increase Maximum Upgrade Levels" will increase all other nodes on the tree by 5.
