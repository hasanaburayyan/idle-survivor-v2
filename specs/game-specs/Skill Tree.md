Overview:
Players will need a few tabs on the bottom of the screen, one labelled "Social" and one labelled "Skill Tree", and one labelled "The Wastes". Each tab will replace the primary screen portion, currently where Scavenge lives. In Social, you'll have a few simple placeholder labels, Friends, Guild, and Recent. No need to explore those concepts yet. Skill Tree will contain a web of nodes which will slowly expand. Off rip it will only have one node visible, and each time you unlock a node, nodes attached to that may or may not become visible. The Wastes tab will contain the current gameplay loop, with the Scavenge button.

Player Level will be a new concept. Clicking most buttons will yield at least 1 xp, and players will now have a account level displayed in their Group badge, go ahead and replace the Scavenge level with this. Assign some arbitrary level up requirement, and increase it slowly per level. Award 1 Skill Point to the player per level up, these are what you will use to unlock and upgrade nodes within the Skill Tree.

The Skill Tree will be a pannable view, starting from one single node and slowly expanding to be a complex web. Each node can be unlocked, and SOME nodes within the web have upgrade levels. This needs to be extensible, as future upgrades may increase maximum upgrade levels.
Nodes will have prerequisite nodes. As a placeholder, simply assign each skill in the Initial Skill Tree to have the previous node as a prerequisite. These will eventually be more complex, requiring specific nodes at specific levels, and sometimes more than one node.

Initial Skill Tree:
Scavenge Base Value: Adds 1 per level to the base value of Scavenge, much like the current Upgrade button does. These can be additive.
Scavenge Percentage Scaling: Adds 1% to the button press value of Scavenge per level. For example, at level 20 it would add 20% total Scavenge to the output.
Group Base Scaling: Adds 1 per level to the base value shared with other players when you contribute to them in the Group.
Group Percent Scaling: Adds 1% per level to the value shared with other players in the group.
